# kokoro-smd

Speech Markdown (`.smd`) ファイルを [Kokoro TTS](https://github.com/hexgrad/kokoro) で音声に変換する CLI ツール。

## セットアップ

```bash
cd Video/Introduction-to-AI_v1/kokoro-smd
mise run setup
```

## 使い方

### 単一ファイルの処理

```bash
mise run speech path/to/script.smd
mise run speech path/to/script.smd --output-dir ./output --gap 1.5 --speed 1.0
```

### ディレクトリ一括処理

```bash
mise run batch ../3_Audio_Scripts/section_00 ../4_Audio/section_00
```

`3_Audio_Scripts/` 内の `.smd` ファイルを再帰的に探し出し、
同じディレクトリ構造を `4_Audio_Output/` にミラーして処理します。


### パース結果の確認 (音声生成なし)

```bash
kokoro-smd parse path/to/script.smd
```

## SMD 記法リファレンス

kokoro-smd が対応しているSpeech Markdown記法の一覧です。

### ファイル全体構造

```markdown
---
01-01 予測系タスク
想定所要時間：約15分
スライド枚数：10枚
---

# [01-01: Slide 1/10] タイトル
本文テキスト…

# [01-01: Slide 2/10] 次のスライド
…
```

### フロントマター

ファイル **先頭** の `---` で囲まれたブロックはメタデータ（フロントマター）として扱われ、音声生成の対象外になります。

```markdown
---
01-01 予測系タスク
想定所要時間：約15分
スライド枚数：10枚
---
```

- `キー: 値` または `キー：値`（半角・全角コロン対応）の行は key-value ペアとして解析されます。
- key-value 形式でない最初の行はドキュメントの **タイトル** として `title` キーに格納されます。
- フロントマターは省略可能です。

### セクション見出し（`#`）

`#` で始まる行がセクションの区切りになります。各セクションは個別の音声ファイルとしてキャッシュされ、最終的に結合されます。

```markdown
# [01-01: Slide 1/10] タイトル「AI入門 第0部 講義の外観」
```

- `[…]` 内はスライド参照情報（`slide_info`）として抽出されます。
- `]` 以降の文字列がセクションの **タイトル**（`heading_title`）になります。
- `[…]` がない場合、行全体がタイトルとして扱われます。

### エイリアス読み（`[表示テキスト](読み)`）

表示テキストの代わりに括弧内の読みがTTSに渡されます。

```markdown
[AI](エーアイ)              → 「エーアイ」と読み上げ
[AI](alias: エーアイ)       → 同上（alias: プレフィックスも対応）
[GPU](ジーピーユー)          → 「ジーピーユー」と読み上げ
[20questions](トゥエンティ・クエスチョンズ)
```

### ブレイク（`[break: 時間]`）

任意の位置に指定した長さの無音を挿入します。

```markdown
文の途中に [break: 500ms] 少し間を空ける。
長めの間。[break: 2s] 次の文。
```

- `ms`（ミリ秒）と `s`（秒）の両方に対応しています。

### 注釈（`[note: …]`）

音声生成から完全に除外されるコメントです。

```markdown
[note: ここでスライドを切り替え]
通常の読み上げテキスト。
```

### スタイルタグ（`#[スタイル名]`）

`#[Normal]` などのスタイル指定タグは除去されます（現在はスタイル切替機能は未実装）。

```markdown
#[Normal] はい、こんにちは。
```

→ 「はい、こんにちは。」として読み上げ

### 空行によるポーズ

本文中の **空行** は **0.5秒** の無音として扱われます。段落間の間を自然にとるための記法です。

```markdown
最初の段落のテキスト。

次の段落のテキスト。（↑ 0.5秒の間が入る）
```

同様に、セクション内の **改行**（非空行間）にも **0.5秒** のポーズが自動挿入されます。

### セクション間ギャップ

セクション（`#` 見出し）間には、`--gap` オプションで指定した長さ（デフォルト **1.0秒**）の無音が挿入されます。
