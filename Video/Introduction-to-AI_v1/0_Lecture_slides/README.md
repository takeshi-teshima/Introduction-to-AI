# PDF分割スクリプトの使い方

このフォルダには、PDFファイルをページごとに分割するためのスクリプト `split_pdf.sh` が含まれています。

## 必要なツール
- pdftk

macOSの場合、Homebrewで以下のコマンドでインストールできます：

```
brew install pdftk-java
```

## 使い方
1. ターミナルでこのフォルダに移動します。
2. 以下のコマンドでスクリプトを実行します：

```
./split_pdf.sh <入力PDFのパス> <タスクリストCSVのパス>
```

- `<入力PDFのパス>`: 分割したいPDFファイルのパス
- `<タスクリストCSVのパス>`: 分割タスクを記載したCSVファイルのパス

### タスクリストCSVの例
```
output_basename,pages_to_extract
00-02,1-3
00-03,4-6
```

## 出力
分割されたPDFは `split_slides` フォルダに保存されます。

## 注意
- pdftkがインストールされていない場合、スクリプトは動作しません。
- PDFにテキストが埋め込まれていない場合、分割後もテキスト抽出できないことがあります。
