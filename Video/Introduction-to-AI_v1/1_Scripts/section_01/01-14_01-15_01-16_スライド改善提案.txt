■ 個別提案

[スライド 3-5: ソフトマックス関数]
提案：**手計算演習を追加**

演習1：ソフトマックスを自分で計算する
  入力：z = [1, 2, 3]

  ステップ1：各要素の指数を計算
    e^1 ≈ 2.72
    e^2 ≈ 7.39
    e^3 ≈ 20.09

  ステップ2：合計を計算
    合計 = 2.72 + 7.39 + 20.09 = 30.20

  ステップ3：正規化
    softmax(z)[0] = 2.72/30.20 ≈ 0.09
    softmax(z)[1] = 7.39/30.20 ≈ 0.24
    softmax(z)[2] = 20.09/30.20 ≈ 0.67

  発見：最大値（z[2]=3）が最大確率（0.67）に対応

[スライド 19-22: LogSumExp関数]
提案：**視覚的な比較を強化**

図の追加：max関数 vs LogSumExp関数
  - 横軸：入力の最大値
  - 縦軸：関数の出力
  - max: 階段状（不連続）
  - LogSumExp: 滑らかな曲線
  → これが「soft」の意味

■ 個別提案

[スライド 3: 階層性のポイント]
提案：**図解を強化**

対比図：
  線形モデル：X → Φ → [θ] → 出力
  NN：X → [W1] → [W2] → [W3] → 出力

  ポイント：パラメータが複数段階に登場

[スライド 7: 活性化関数]
提案：**インタラクティブな比較**

演習：各活性化関数の振る舞い
  入力：x = [-2, -1, 0, 1, 2]

  ReLU: [0, 0, 0, 1, 2]
  Sigmoid: [0.12, 0.27, 0.5, 0.73, 0.88]
  Tanh: [-0.96, -0.76, 0, 0.76, 0.96]

  発見：ReLUは最も単純、計算が速い

[スライド 13: 非線形性の必要性]
提案：**証明を視覚化**

例：2層の線形ネット
  f(x) = W2(W1x) = (W2W1)x = Wx
  → 1層と等価！

  グラフで示す：
  - 線形×線形 = 線形
  - 非線形を挟むと複雑な関数に
