[スライド 5-9: 帰納の問題の導入]
- 現状：太陽の例から帰納の問題を説明している
- 提案：**インタラクティブな思考実験を追加**

  **演習1：帰納的推論の限界を体験する**
  問：以下の数列の次の項を予測してください
  　2, 4, 6, 8, ?

  多くの人は「10」と答えるが、実は以下の式でも説明可能：
  　f(n) = n² - n + 2
  この式では、n=5のとき f(5) = 25 - 5 + 2 = 22

  発見すべきポイント：
  - 有限の観測から一般則を決定することは本質的に不可能
  - 「単純な規則」を好むのは我々の仮定（帰納バイアス）
  - 機械学習も同じ問題に直面している

  この演習で、抽象的な「帰納の問題」を数列予測という
  具体的な体験として理解できる


[スライド 13-17: ノーフリーランチ定理]
- 現状：概念の説明は丁寧だが、抽象的で具体例が不足
- 提案：**具体的な対比実験を示す**

  **演習2：NFLを体感するミニ実験**

  状況設定：2つの予測器AとBを用意
  - 予測器A：「直線的なパターンが得意」（線形回帰）
  - 予測器B：「複雑なパターンが得意」（高次多項式）

  タスク1（直線的データ）：
  　X: 1, 2, 3, 4
  　Y: 2, 4, 6, 8
  　→ 予測器Aが優秀（誤差小）

  タスク2（複雑なパターン）：
  　X: 1, 2, 3, 4
  　Y: 1, 4, 1, 4（sin波のような）
  　→ 予測器Bが優秀

  発見すべきポイント：
  - 「あらゆる問題で優秀」な予測器は存在しない
  - 特定の問題設定に特化することで初めて性能が出る
  - 仮定を置く＝特定の問題領域に特化すること

  グラフ提案：横軸に「問題の種類」、縦軸に「性能」を取り、
  予測器Aと予測器Bの性能曲線が交差する様子を視覚化


[スライド 18-20: 事前知識と帰納バイアス]
- 現状：用語の定義は明確だが、実践的な例が不足
- 提案：**機械学習の実例との対応を明示**

  **演習3：身近な機械学習手法の帰納バイアスを特定する**

  問：以下の各手法が「どんな仮定」を置いているか考えよ

  1. 線形回帰
     答：「入出力の関係は直線（または平面）で近似できる」
     帰納バイアス：単純さを好む（複雑な曲線を避ける）

  2. k近傍法（k-NN）
     答：「近くのデータ点は似た出力を持つ」
     帰納バイアス：局所的な類似性を信じる

  3. L2正則化
     答：「パラメータは小さい値を取るべき」
     帰納バイアス：過度に大きな重みを避ける

  4. 決定木
     答：「特徴空間を直角に区切って分類できる」
     帰納バイアス：階層的な決定境界を好む

  発見すべきポイント：
  - 全ての機械学習手法は何らかの帰納バイアスを持つ
  - 帰納バイアスがないと学習は不可能（NFL定理）
  - 問題に合った帰納バイアスを選ぶことが手法選択の本質

- 確率論の予備知識（条件付き分布、期待値、分位点）の説明が充実

■ 個別提案

[スライド 1-5: 近似ターゲットの概念]
- 現状：モデル内最適 vs あらゆる関数内最適の対比が明確
- 提案：**視覚的な図解の強化**

  図の改善提案：
  - 「モデルの箱」と「あらゆる予測器の空間」を色分け
  - モデル内最適解（濃い青）とグローバル最適解f*（赤）を明示
  - 「近似誤差」（f*とモデル内最適解の距離）を矢印で示す

  追加の具体例：
  　例：線形モデルで非線形な真の関係を近似する場合
  　- 真の関係 f*(x) = x²
  　- 線形モデル f(x) = wx + b
  　→ どんなにw, bを調整しても、f*には到達できない
  　→ これが「近似誤差」（approximation error）


[スライド 6-14: 予備知識（確率論）]
- 現状：定義は正確だが、実際に計算する機会が不足
- 提案：**段階的な計算演習を追加**

  **演習1：条件付き期待値を実際に計算する**

  設定：X ∈ {1, 2}, Y ∈ {0, 1}の離散的な場合

  同時分布が以下で与えられる：
  　P(X=1, Y=0) = 0.2
  　P(X=1, Y=1) = 0.3
  　P(X=2, Y=0) = 0.1
  　P(X=2, Y=1) = 0.4

  ステップ1：周辺分布P(X)を求めよ
  　P(X=1) = 0.2 + 0.3 = 0.5
  　P(X=2) = 0.1 + 0.4 = 0.5

  ステップ2：条件付き分布P(Y|X=1)を求めよ
  　P(Y=0|X=1) = P(X=1,Y=0)/P(X=1) = 0.2/0.5 = 0.4
  　P(Y=1|X=1) = P(X=1,Y=1)/P(X=1) = 0.3/0.5 = 0.6

  ステップ3：条件付き期待値E[Y|X=1]を求めよ
  　E[Y|X=1] = 0×0.4 + 1×0.6 = 0.6

  ステップ4：同様にE[Y|X=2]を求めよ
  　E[Y|X=2] = 0×0.2 + 1×0.8 = 0.8

  発見すべきポイント：
  - 条件付き期待値はXの各値に対して定まる（関数）
  - これが「近似ターゲット」の候補になる
  - 損失関数によって、目指すべきターゲットが変わる


[スライド 11-14: 分位点と期待値の違い]
- 現状：外れ値への頑健性の説明が定性的
- 提案：**数値実験で違いを体感**

  **演習2：期待値 vs 中央値の比較実験**

  データ：10人の年収（単位：万円）
  　300, 320, 350, 370, 400, 420, 450, 480, 500, 8000

  問1：平均値（期待値）を計算せよ
  　答：(300+320+...+500+8000)/10 = 1109万円

  問2：中央値（50%分位点）を求めよ
  　答：ソートして真ん中2つの平均
  　　　(400+420)/2 = 410万円

  問3：「代表的な年収」を表すにはどちらが適切か？
  　答：中央値（410万円）
  　理由：1人の高額所得者（8000万円）が平均値を大きく歪めている

  問4：もし最高年収者のデータが誤りで、実は800万円だったら？
  　平均値：(1109×10 - 8000 + 800)/10 = 389万円（大きく変化）
  　中央値：400万円前後（ほとんど変化なし）

  発見すべきポイント：
  - 期待値は外れ値に敏感
  - 中央値（分位点）は外れ値に頑健
  - 予測タスクでも同じ：損失関数の選択で頑健性が変わる


[スライド 15-22: 損失関数と近似ターゲットの対応]
- 現状：理論的な対応関係は明確だが、なぜそうなるかの直感が不足
- 提案：**視覚的な最適化の様子を示す**

  **演習3：2乗損失 vs 絶対値損失の最適解を比較**

  設定：X=5のとき、Yが以下の分布に従う
  　Y ∈ {0, 2, 10}
  　P(Y=0|X=5) = 0.4
  　P(Y=2|X=5) = 0.4
  　P(Y=10|X=5) = 0.2

  問1：予測値をcとするとき、2乗損失の期待値を最小化するcは？
  　E[(Y-c)²|X=5] = (0-c)²×0.4 + (2-c)²×0.4 + (10-c)²×0.2
  　を最小化
  　→ 微分して0: -2c×0.4 - 2(2-c)×0.4 - 2(10-c)×0.2 = 0
  　→ 答：c = E[Y|X=5] = 0×0.4 + 2×0.4 + 10×0.2 = 2.8

  問2：絶対値損失の期待値を最小化するcは？
  　E[|Y-c||X=5]を最小化
  　→ 答：c = 中央値 = 2（累積確率が50%を超える点）

  問3：2つの解（2.8 vs 2）の違いの理由は？
  　答：Y=10という外れ値が期待値を引き上げている
  　　　中央値は外れ値の影響を受けにくい

  発見すべきポイント：
  - 損失関数が変われば、目指すべきターゲットも変わる
  - 2乗損失 → 条件付き期待値
  - 絶対値損失 → 条件付き中央値
  - タスクに応じて適切な損失関数を選ぶことが重要

■ 個別提案

[スライド 1-2: 分類タスクの定義と例]
- 現状：回帰との対比が明確で、複数の例が提示されている
- 提案：**クイズ形式で分類 vs 回帰を判別する演習**

  **演習1：これは分類？それとも回帰？**

  以下のタスクが「分類」か「回帰」かを判定し、理由を述べよ

  タスク1：顧客の年齢・性別から、購入金額を予測
  　答：回帰（購入金額は量的変数）

  タスク2：顧客の年齢・性別から、購入する/しないを予測
  　答：分類（購入有無は質的変数、2クラス）

  タスク3：過去1週間の気温から、明日の最高気温を予測
  　答：回帰（気温は量的変数、連続値）

  タスク4：過去1週間の気温から、明日の天気（晴れ/曇り/雨）を予測
  　答：分類（天気は質的変数、3クラス）

  タスク5：レビュー文から、星の数（1〜5）を予測
  　答：どちらとも解釈可能！
  　- 回帰として扱う：星の数を連続値の近似として予測
  　- 分類として扱う：5つのクラスのどれかを予測
  　→ 実務では分類として扱うことが多い

  発見すべきポイント：
  - ラベルの性質（量的 vs 質的）で判断
  - 順序関係に意味があるか？（星5は星1の5倍良い？）
  - 同じデータでも解釈次第で変わることもある


[スライド 3: 2クラス分類の用語]
- 現状：用語の定義は網羅的だが、なぜこの用語が必要かの説明が不足
- 提案：**実例との対応で用語の必要性を理解**

  **演習2：医療診断での用語の重要性**

  設定：病気の診断タスク
  　X：患者の検査結果
  　Y：病気あり（+1）/ 病気なし（-1）

  用語の対応：
  - 正例（positive example）：病気あり
  - 負例（negative example）：病気なし

  予測器の4つの結果：
  1. True Positive (TP)：病気ありと予測 → 実際に病気あり ✓
  2. False Positive (FP)：病気ありと予測 → 実際は病気なし ✗
  3. True Negative (TN)：病気なしと予測 → 実際に病気なし ✓
  4. False Negative (FN)：病気なしと予測 → 実際は病気あり ✗

  問：どのエラーがより深刻か？
  　答：FN（病気を見逃す）の方が、FP（誤警報）より深刻
  　→ これが後の「コスト考慮型損失」に繋がる

  発見すべきポイント：
  - 2クラス分類では「どちらを正」とするかが重要
  - 正/負の用語は、その後の評価指標で必須
  - エラーの種類によって重要度が異なる


[スライド 4: 0/1損失と誤分類率]
- 現状：定義は明確だが、実際の計算例が不足
- 提案：**小さなデータで誤分類率を計算する**

  **演習3：誤分類率を実際に計算する**

  データ：5個のテストデータ
  　真のラベル Y：[+1, +1, -1, +1, -1]
  　予測器Aの予測 f_A(X)：[+1, -1, -1, +1, -1]
  　予測器Bの予測 f_B(X)：[+1, +1, +1, +1, -1]

  問1：予測器Aの0/1損失を各データで計算せよ
  　データ1：Y=+1, f_A=+1 → 一致 → 損失=0
  　データ2：Y=+1, f_A=-1 → 不一致 → 損失=1
  　データ3：Y=-1, f_A=-1 → 一致 → 損失=0
  　データ4：Y=+1, f_A=+1 → 一致 → 損失=0
  　データ5：Y=-1, f_A=-1 → 一致 → 損失=0

  問2：予測器Aの誤分類率は？
  　答：(0+1+0+0+0)/5 = 1/5 = 0.2 = 20%

  問3：予測器Bの誤分類率は？
  　損失：[0, 0, 1, 0, 0]
  　誤分類率：1/5 = 20%

  問4：2つの予測器の性能は同じか？
  　答：誤分類率は同じだが、間違え方が違う
  　→ タスクによってはFPとFNの重要度が異なる
  　→ 0/1損失以外の評価が必要な場合もある


[スライド 5-6: 2段階アプローチ]
- 現状：概念の説明は明確だが、なぜこのアプローチが必要かの理由が不足
- 提案：**直接アプローチとの対比で理解**

  **演習4：なぜスコア→決定規則の2段階にするのか？**

  状況1：質的出力を直接扱う場合の困難
  　- ラベル{猫, 犬, パンダ}を直接予測
  　- 問題：「猫に近づける」という操作ができない
  　- 問題：微分などの数学的操作が適用できない

  状況2：スコアを経由する場合
  　- まずスコアZ ∈ ℝを出力（例：犬らしさ = 2.5）
  　- スコアは実数なので微分可能、最適化可能
  　- その後、スコアから決定規則でラベルを選択

  具体例：スパムフィルタ
  　ステップ1：メールのスパムらしさスコア Z を計算
  　　Z = -3.2（明らかに正常メール）
  　　Z = 0.5（微妙なメール）
  　　Z = 5.8（明らかにスパム）

  　ステップ2：閾値（例：Z > 0）でスパム判定
  　　Z = -3.2 → 正常メール
  　　Z = 0.5 → スパム
  　　Z = 5.8 → スパム

  発見すべきポイント：
  - 質的出力は直接最適化できない
  - 実数値スコアを経由することで最適化が可能に
  - 閾値を変えれば、誤検出と見逃しのトレードオフを調整可能


[スライド 7: 0/1損失の最適化の難しさ]
- 現状：微分が0であることの問題は説明されているが、視覚的理解が不足
- 提案：**グラフを使った視覚的説明の強化**

  図の改善提案：
  1. ステップ関数のグラフに「微分=0」のラベルを明示
  2. 対比として「滑らかな損失関数」（シグモイドなど）を併記
  3. 「こちらは微分が使える！」と視覚的に示す

  追加の演習：
  　**なぜ微分が必要なのか？**

  　勾配法の復習：
  　　θ_new = θ_old - η × ∂L/∂θ

  　0/1損失の場合：
  　　∂L/∂θ = 0（ほとんどいたるところで）
  　　→ θ_new = θ_old（パラメータが更新されない！）

  　滑らかな損失の場合：
  　　∂L/∂θ ≠ 0（適切な勾配が得られる）
  　　→ 損失を減らす方向にパラメータが更新される


[スライド 10: ベイズ分類器]
- 現状：定義式は示されているが、なぜこれが最適かの直感が不足
- 提案：**小規模な例で最適性を確認**

  **演習5：ベイズ分類器が最適であることを確認**

  設定：X ∈ {A, B}, Y ∈ {1, 2, 3}の3クラス分類

  条件付き確率が以下で与えられる：
  　X=Aの場合：
  　　P(Y=1|X=A) = 0.5
  　　P(Y=2|X=A) = 0.3
  　　P(Y=3|X=A) = 0.2

  　X=Bの場合：
  　　P(Y=1|X=B) = 0.1
  　　P(Y=2|X=B) = 0.2
  　　P(Y=3|X=B) = 0.7

  問1：ベイズ分類器f*はどのように予測するか？
  　X=A → argmax {0.5, 0.3, 0.2} = 1
  　X=B → argmax {0.1, 0.2, 0.7} = 3

  問2：ベイズ分類器の誤分類率は？
  　X=Aの時の誤り確率：1 - 0.5 = 0.5
  　X=Bの時の誤り確率：1 - 0.7 = 0.3
  　（※ P(X)も考慮する必要があるが、ここでは簡略化）

  問3：別の分類器（例：常にY=1と予測）と比較せよ
  　常にY=1の場合：
  　　X=Aの時の誤り確率：1 - 0.5 = 0.5
  　　X=Bの時の誤り確率：1 - 0.1 = 0.9
  　→ ベイズ分類器の方が優れている

  発見すべきポイント：
  - 各Xに対して、最も確率が高いクラスを選ぶのが最適
  - これ以上誤分類率を下げることは（確率的に）不可能
  - したがってP(Y|X)を学習することが目標になる
