[スライド 2-3: 確率論的分類の基本的な見方]
- 現状：ベイズ分類器の式とP(Y|X)推定の方針を説明
- 提案：**具体的な数値例で理解を固める**

  **演習1：ベイズ分類器を手計算で確認する**

  設定：2クラス分類（スパムか通常メールか）、特徴量X=メール長さ

  ケース1：短いメール（X=short）
    P(Y=spam|X=short) = 0.7
    P(Y=normal|X=short) = 0.3

    問：ベイズ分類器の予測は？
    答：argmax {0.7, 0.3} = spam

  ケース2：長いメール（X=long）
    P(Y=spam|X=long) = 0.2
    P(Y=normal|X=long) = 0.8

    問：ベイズ分類器の予測は？
    答：argmax {0.2, 0.8} = normal

  発見すべきポイント：
  - P(Y|X)さえ分かれば、最適な分類ができる
  - 問題は「P(Y|X)をどう推定するか」
  - これが確率論的分類の核心


[スライド 5-7: 確率値ベクトルとモデルの要件]
- 現状：確率値ベクトルの定義と要件を説明
- 提案：**不適切なモデルと適切なモデルの対比**

  **演習2：このモデルは確率値ベクトルを出力できるか？**

  モデル1：線形モデル f(x) = wx + b
    問：x=5のとき、w=1, b=-3なら出力は？
    答：f(5) = 1×5 + (-3) = 2
    問題：確率なのに1より大きい！NG！

  モデル2：線形モデル + 正規化
    f_k(x) = exp(w_k·x + b_k) / Σ_j exp(w_j·x + b_j)

    検証：
    - 各f_k(x) ≥ 0（指数関数なので必ず正）✓
    - Σ_k f_k(x) = 1（分母と分子が同じ和）✓
    → これなら確率値ベクトルになる！

  発見すべきポイント：
  - 単純な線形モデルは確率の要件を満たさない
  - 何らかの変換（softmax等）が必要
  - これが次のスライドで導入される


[スライド 10-13: 交差エントロピー損失とKLダイバージェンス]
- 現状：交差エントロピーとKLダイバージェンスの関係を説明
- 提案：**視覚的・数値的な理解を強化**

  **演習3：交差エントロピーを実際に計算する**

  設定：3クラス分類、1つのデータ点
    真のラベル：Y = class 2（つまり[0,1,0]のone-hot）

  モデルAの予測確率：
    P_A(Y=1|x) = 0.2
    P_A(Y=2|x) = 0.7  ← 正解クラス
    P_A(Y=3|x) = 0.1

  モデルBの予測確率：
    P_B(Y=1|x) = 0.4
    P_B(Y=2|x) = 0.3  ← 正解クラス
    P_B(Y=3|x) = 0.3

  問1：モデルAの交差エントロピー損失は？
    H(q, P_A) = -log P_A(Y=2|x) = -log(0.7) ≈ 0.36

  問2：モデルBの交差エントロピー損失は？
    H(q, P_B) = -log P_B(Y=2|x) = -log(0.3) ≈ 1.20

  問3：どちらのモデルがより良い？
    答：モデルA（損失が小さい）
    理由：正解クラスに高い確率を割り当てている

  発見すべきポイント：
  - 交差エントロピー損失は「正解クラスへの確率」で決まる
  - 正解クラスの確率が高いほど損失は小さい
  - これを最小化 = 正解クラスの確率を最大化

[スライド 2-3: 繰り返し期待値の公式]
- 現状：Law of Iterated Expectationsの説明
- 提案：**具体的な計算例で直感を養う**

  **演習1：繰り返し期待値の公式を数値で確認**

  設定：離散的な確率変数
    X ∈ {1, 2}, Y ∈ {0, 1, 2}

  同時分布P(X, Y)：
    P(1,0)=0.1  P(1,1)=0.2  P(1,2)=0.1  → P(X=1)=0.4
    P(2,0)=0.1  P(2,1)=0.3  P(2,2)=0.2  → P(X=2)=0.6

  方法1：直接Yの期待値を計算
    E[Y] = 0×(0.1+0.1) + 1×(0.2+0.3) + 2×(0.1+0.2)
         = 0×0.2 + 1×0.5 + 2×0.3
         = 0 + 0.5 + 0.6 = 1.1

  方法2：繰り返し期待値
    E[Y|X=1] = (0×0.1 + 1×0.2 + 2×0.1)/0.4 = 0.4/0.4 = 1.0
    E[Y|X=2] = (0×0.1 + 1×0.3 + 2×0.2)/0.6 = 0.7/0.6 ≈ 1.17

    E[E[Y|X]] = E[Y|X=1]×P(X=1) + E[Y|X=2]×P(X=2)
               = 1.0×0.4 + 1.17×0.6
               = 0.4 + 0.7 = 1.1 ✓

  発見すべきポイント：
  - 2つの方法で同じ答えになる
  - 「条件付けて期待値→さらに期待値」の入れ子構造
  - この性質が証明の核心


[スライド 4-9: 各損失関数の証明]
- 現状：4つの証明アウトラインを提示
- 提案：**証明の共通パターンを強調**

  **新規スライド提案：「全ての証明に共通する戦略」**
  挿入位置：スライド4の前

  タイトル：「証明の共通パターン」

  全ての証明は同じ3ステップで進む：

  【STEP 1】リスク関数を条件付き期待値で分解
    R(f) = E_X,Y[L(Y, f(X))]
         = E_X[E_Y|X[L(Y, f(X))]]  ← Law of Iterated Expectations

  【STEP 2】内側の期待値を最小化
    各Xに対して、E_Y|X[L(Y, f(X))]を最小にするf(X)を探す
    → これが近似ターゲットf*(X)

  【STEP 3】全体のリスクも最小
    各Xで内側が最小 ⇒ 外側の期待値も最小
    → f*がグローバルに最適

  損失関数が変わると：
  - STEP 1は常に同じ（Law of Iterated Expectations）
  - STEP 2で解く問題が変わる
    * 2乗損失 → 条件付き期待値
    * 絶対値損失 → 条件付き中央値
    * 0-1損失 → 最大事後確率
    * 交差エントロピー → 真の条件付き確率


[スライド 4-6: 2乗損失の証明]
- 現状：展開と式変形を提示

  改善案：スライド上の数式に、右側に小さく「なぜ？」の注釈

  E[(Y - f(X))²|X]
  = E[Y² - 2Yf(X) + f(X)²|X]          ← 展開
  = E[Y²|X] - 2f(X)E[Y|X] + f(X)²     ← 期待値の線形性

  = [f(X) - E[Y|X]]² + E[Y²|X] - E[Y|X]²  ← 平方完成
    └─ これを最小化 ─┘   └─ 定数項 ─┘

  最小化の条件：
  f(X) = E[Y|X]  ← これが近似ターゲット！

[スライド 6-10: シグモイド関数とロジスティック回帰]
- 現状：シグモイド関数の導入と性質
- 提案：**インタラクティブな理解**

  **演習2：シグモイド関数の振る舞いを確認**

  シグモイド関数：σ(z) = 1 / (1 + e^(-z))

  問1：以下の値を計算せよ
    σ(0) = 1/(1+e^0) = 1/2 = 0.5
    σ(2) = 1/(1+e^(-2)) ≈ 0.88
    σ(-2) = 1/(1+e^2) ≈ 0.12
    σ(10) = 1/(1+e^(-10)) ≈ 1.0
    σ(-10) = 1/(1+e^10) ≈ 0.0

  問2：σ(z) + σ(-z) = ?
    計算：
    σ(z) + σ(-z) = 1/(1+e^(-z)) + 1/(1+e^z)
                  = [1+e^z + 1+e^(-z)] / [(1+e^(-z))(1+e^z)]
                  = [e^z + e^(-z) + 2] / [e^z + e^(-z) + 2]
                  = 1

    対称性：σ(z)が0.7なら、σ(-z)は0.3

  問3：ロジスティック回帰モデルで、
       g_θ(x) = σ(w·x + b) = 0.5 となる条件は？
    答：w·x + b = 0
    → これが決定境界！

  発見すべきポイント：
  - シグモイドは滑らかなS字カーブ
  - 中心（z=0）で0.5を通る
  - 決定境界は線形（w·x + b = 0）


[スライド 11-21: 勾配降下法]
- 現状：勾配降下法の詳細な説明
- 提案：**ステップバイステップの手計算例**

  **演習3：勾配降下法を1ステップ実行する**

  超シンプルな例：1次元入力、1つのデータ
    データ：(x,y) = (2, 1)  ← x=2のとき、y=1（クラス1）
    モデル：g_θ(x) = σ(wx)  ← バイアスなし、w∈ℝ

  初期値：w = 0

  ステップ1：予測を計算
    z = w×x = 0×2 = 0
    g(x) = σ(0) = 0.5

  ステップ2：損失を計算
    L = -[y log g(x) + (1-y) log(1-g(x))]
      = -[1×log(0.5) + 0×log(0.5)]
      = -log(0.5) ≈ 0.69

  ステップ3：勾配を計算
    ∂L/∂w = -(y - g(x))×x
          = -(1 - 0.5)×2
          = -1.0

  ステップ4：パラメータを更新
    w_new = w - η × (∂L/∂w)
          = 0 - 0.1 × (-1.0)  ← 学習率η=0.1
          = 0.1

  ステップ5：改善を確認
    新しい予測：g(x) = σ(0.1×2) = σ(0.2) ≈ 0.55
    → 0.5から0.55に改善（正解y=1に近づいた！）

  発見すべきポイント：
  - 勾配が「改善の方向」を指す
  - 学習率は「どれだけ動くか」を制御
  - 1ステップずつ正解に近づく

     g_θ(x) = σ(w·x + b) = 1/(1 + exp(-(w·x + b)))

  □ Q2: なぜシグモイド関数が必要？
     → 出力を[0,1]に制限して確率値にするため

  □ Q3: 交差エントロピー損失の式は？
     L = -[y log g(x) + (1-y) log(1-g(x))]

  □ Q4: 決定境界の式は？
     w·x + b = 0

  □ Q5: 勾配降下法の更新式は？
     θ_new = θ_old - η × ∇L(θ_old)

  □ Q6: ロジスティック回帰の限界は？
     → 線形分離しかできない
     → 非線形パターンには向かない

  これらに答えられれば、このセクションは完璧です！
