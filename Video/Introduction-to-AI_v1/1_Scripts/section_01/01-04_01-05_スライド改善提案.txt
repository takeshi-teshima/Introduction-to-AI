[スライド 5-6: 線形モデルの定義]
- 現状：「パラメータθに関して線形」という核心概念を説明
- 提案：**理解確認クイズスライドを追加**

**クイズ：次のうち、パラメータθに関して線形なモデルはどれ？**
```
A) f(x) = θ₁x + θ₂x²
B) f(x) = θ₁/(1 + θ₂x)
C) f(x) = sin(θ₁x + θ₂)
D) f(x) = θ₁sin(x) + θ₂cos(x)
```

**正解：A と D**
**解説：**
- A: θ₁とθ₂それぞれに1次の項。線形モデル。
- B: θ₂が分母にあり、θに関して非線形。
- C: θ₁が三角関数の引数内にあり、θに関して非線形。
- D: θ₁とθ₂が係数として掛けられているだけ。線形モデル。

このクイズにより、「データxが非線形でもOK」「パラメータθが線形であることが重要」
という本質的理解が確認できる。

**よくある誤解チェック**

「Q: この解は、訓練データに対する誤差を0にする解である。○か×か？」
→ ×。訓練データに対する2乗誤差の『総和』を最小化する解。

このチェックにより、最小二乗法の意味と限界を明確化。

[スライド 7: なぜ過適合が起こるか]
- 現状：「大きなパラメータ値が必要」という説明
- 提案：**視覚的な直感構築スライドを追加**

「なめらかな曲線 vs ガタガタの曲線」を並べて表示。

「左：なめらかな曲線（小さいパラメータ）
 - 各データ点には完璧に合わないが、全体的な傾向を捉える
 - パラメータ: θ = [1.0, -0.3, 0.05]

 右：ガタガタの曲線（大きいパラメータ）
 - 各データ点にぴったり合うが、激しく振動
 - パラメータ: θ = [100, -350, 420, -180]

過適合したモデルは、大きなパラメータで激しく振動することで、
訓練データの細かいノイズまで『暗記』してしまいます。」


[スライド 8-9: ノルムと正則化の導入]
- 現状：L2ノルムの定義と正則化項の説明
- 提案：**理解確認クイズを追加**

**クイズ：正則化の効果**

「正則化項 λ||θ||² を経験リスクに加えると、何が起こる？

A) パラメータθが0に近づく
B) 訓練誤差が必ず減る
C) テスト誤差が必ず減る
D) モデルの複雑さが抑えられる

複数選択可」

**正解：A と D**
**解説：**
- A: ○ 正則化項はパラメータの大きさにペナルティを課すため、θは小さくなる傾向
- B: × 正則化により訓練誤差は増える（トレードオフ）
- C: × λが大きすぎると未学習になり、テスト誤差も増える
- D: ○ パラメータが小さい → なめらかな関数 → 複雑さが抑制

[新規スライド提案] 正則化の直感的理解スライド

**タイトル：「正則化 = 複雑さとデータ適合のバランス」**

天秤の図：
左の皿：「訓練データへの適合」（経験リスク項）
右の皿：「モデルの単純さ」（正則化項）

λが小さい → 左の皿が重い → データに合わせすぎ → 過適合
λが大きい → 右の皿が重い → 単純すぎる → 未学習
λが適切 → バランスが取れる → 汎化性能が高い

このバランス感覚が正則化の本質。

[スライド 14-18: 正則化の種類]
- 現状：L1正則化（Lasso）、L2正則化（Ridge）の説明
- 提案：**視覚的な比較スライドを追加**

「L1 vs L2：何が違う？」

並列比較表：
```
                L1 (Lasso)              L2 (Ridge)
------------------------------------------------------
ペナルティ      |θ|の和                θ²の和
効果            スパース性              なめらかな縮小
                (一部のθが厳密に0)      (全てのθが小さく)
使い所          特徴選択が必要          全特徴を保持
例              1000個の遺伝子から       画像の全ピクセルを
                重要な10個を選ぶ         使うが重みを小さく
```

視覚的に、L1は「角のある制約領域」、L2は「円形の制約領域」として表示。


[新規スライド提案] 誤解の事前チェック

**よくある誤解チェック**

「Q1: 正則化すれば、必ず汎化性能が向上する。○か×か？」
→ × λが大きすぎると未学習になる。適切な調整が必要。

「Q2: 正則化は、訓練データが少ない時にのみ必要である。○か×か？」
→ × データが多くても、モデルが複雑なら過適合は起こる。
    正則化は汎化性能向上の一般的な技法。

「Q3: L1正則化で、重要でない特徴のθが0になるのは偶然である。○か×か？」
→ × L1ノルムの性質により、数学的に必然的にスパース解が得られる。
