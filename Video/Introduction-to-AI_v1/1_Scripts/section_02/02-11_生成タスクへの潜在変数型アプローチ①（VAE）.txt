■ スライド 1／12：生成タスクへの潜在変数型アプローチ①（VAE）
----------------------------------------

今回のセクションでは、生成タスクにおける潜在変数型のアプローチの中でも、最も代表的で重要な手法の一つである VAE、変分オートエンコーダー（Variational Autoencoder）について詳しく学んでいきます。

前回のセクション（02-10）では、潜在変数型アプローチの基本的な考え方を説明しました。今回は、その理論的な基礎と、実装の際に必要になる重要なテクニックを、数式を交えながら詳しく掘り下げていきます。

VAEは、一見すると複雑に見えるかもしれませんが、その基本的なアイデアは比較的シンプルです。段階的に理解していきましょう。

■ スライド 2／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（概観）
----------------------------------------

VAEは現在、画像生成モデルの重要な部品として、広く使われています。

その基本的な考え方は次のようなものです。学習済みのデコーダー、あるいは生成器と呼ばれるニューラルネットワークを用意します。このネットワークは「潜在表現」と呼ばれるベクトルを入力すると、そこから画像を出力します。

具体的には、例えばランダムな潜在変数をデコーダーに入力すると、様々な手書き数字が生成されるといった具合です。

このアプローチの素晴らしいところは、潜在空間全体が「構造化」されているために、どの点からデータを生成しても、意味のある出力が得られるということです。この特性を実現するのが、VAEの重要な役割なのです。

■ スライド 3／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（積分の問題）
----------------------------------------

では、変分オートエンコーダーの着想を説明していきます。

まず、生成器のモデルを定式化します。潜在変数の分布から、生成器を通して、出力を中心とする正規分布へ変換される、というモデルを考えます。

このモデルから、原理的には次の式でデータの密度関数を導出することができます：

p_θ(x) = ∫ p_θ(x|z) · p(z) dz

ここで p_θ(x) はデータ x が生成される確率、p_θ(x|z) はそれぞれの潜在変数 z が与えられたときの条件付き確率、そして p(z) は潜在変数の事前分布です。

この式から、最尤法ベースの学習をしたいというのが自然な発想です。しかし、ここに問題が生じます。この積分は、計算時間的に実行不能です。

潜在変数の次元が高いほど、この積分の計算は指数的に困難になります。そこで、VAEは巧妙なトリックを使って、この問題を解決するのです。

■ スライド 4／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs ＞ 着想
（ベイズの定理）
----------------------------------------

ベイズの定理は、生成モデル学習における重要なツールです。まずベイズの定理を思い出しましょう。

周辺尤度（marginal likelihood）がわかれば、事後分布を計算することができます：

p(z|x) = p(x|z) · p(z) / p(x)

逆に、事後分布がわかれば、周辺尤度を計算することができます：

p(x) = p(x|z) · p(z) / p(z|x)

ここで、どちらの分布も直接わかっていないという問題があります。しかし、事後分布を近似するモデルを用意することにすれば、非常に上手いトリックが使えるのです。

実は、このトリックが使っているのが「エンコーダー」なのです。つまり、エンコーダーという別のニューラルネットワークを用意して、事後分布の近似をさせるというアイデアです。

■ スライド 5／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs ＞ 着想
（エンコーダーとKL等式）
----------------------------------------

では、エンコーダーの役割を説明します。

エンコーダーには、生成器（デコーダー）から決まる確率モデルの事後分布の近似をさせます。これを次のように表記します：

q_ψ(z|x) := Enc_ψ(x)(z)

ここで q_ψ(z|x) は、パラメーター ψ を持つエンコーダーが出力する近似事後分布です。

一方、真の事後分布は次のように表されます：

p_θ(z|x) = p_θ(x,z) / p_θ(x)

ここが重要なポイントです。実は、次の関係を数学的に示すことができるのです：

KL[q_ψ(z|x) ‖ p_θ(z|x)] = log p_θ(x) - ELBO(g_θ, Enc_ψ, x)

つまり、真の事後分布とエンコーダーの出力の乖離、すなわち KL ダイバージェンスは、データの対数尤度とELBOの差分に等しいのです。

したがって、Min_ψ KL[q_ψ(z|x) ‖ p_θ(z|x)] による事後分布の近似をするなら、次を実行すればよいのです：

Min_ψ [ -ELBO(g_θ, Enc_ψ, x) ]

つまり、ELBOを最大化することで、エンコーダーが真の事後分布に近づくというわけです。

■ スライド 6／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs ＞ 着想
（等式の証明）
----------------------------------------

先ほどの等式を導出してみましょう。次の関係式：

KL[q_ψ(z|x) ‖ p_θ(z|x)] = log p_θ(x) - ELBO(g_θ, Enc_ψ, x)

この証明を簡潔に説明します。

まず、-ELBO(g_θ, Enc_ψ, x) を次のように定義します：

-ELBO(g_θ, Enc_ψ, x) := E_{z~Enc_ψ(x)}[log Enc_ψ(x)(z) - log p_θ(x,z)]

この定義から出発して数式を展開することで、上の等式が導出されます。

KL ダイバージェンスは常に非負です（KL[q||p] ≥ 0）ので、この等式から次が導かれます：

log p_θ(x) ≥ ELBO(g_θ, Enc_ψ, x)

つまり、ELBO は対数尤度の下界（lower bound）になっているのです。これが「ELBO」の名前の由来です：Evidence Lower BOund。

■ スライド 7／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs ＞ 着想
（ELBOの式変形）
----------------------------------------

では、ELBOをさらに式変形してみます。

先ほどの定義から出発して、期待値の性質を使って展開すると、次のように書き直すことができます：

-ELBO = E[-log p_θ(x|z)] + KL(Enc_ψ(x) ‖ p(z))

この式には、非常に重要な意味があります。

第一項 E[-log p_θ(x|z)] は「再構成誤差」と呼ばれます。これは、潜在変数 z が与えられたときに、元のデータ x がどの程度よく生成されるかを表しています。

第二項 KL(Enc_ψ(x) ‖ p(z)) は「KL ダイバージェンス」で、これは「正則化項」として機能します。これは、エンコーダーが出力する分布が、事前分布 p(z)（通常は標準正規分布）からどの程度逸脱しているかを表しています。

つまり、-ELBO は：

再構成誤差 + 正則化項

という損失関数に一致するのです。このような形の損失関数は、機械学習で頻出するパターンです。

■ スライド 8／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs ＞ 着想
（生成器の学習）
----------------------------------------

では、生成器（デコーダー）はどのように学習されるのでしょうか。

変分オートエンコーダーの着想において、生成器部分も、そのまま -ELBO(g_θ, Enc_ψ, x) を損失関数とする最小化で学習されます：

Min_θ [ -ELBO(g_θ, Enc_ψ, x) ]

ここで重要なポイントがあります。もし、エンコーダー q_ψ(z|x) が良い仕事をして、実際に KL 項を最小化してくれれば、その結果として、生成器は -ELBO の最小化だけで log p_θ(x) の最大化になるのです。

つまり、エンコーダーの最適化がうまくいっていれば、生成器も間接的に対数尤度を最大化できる、ということです。

言い換えると、エンコーダーと生成器の両者を協働させることで、難しい積分を直接計算することなく、データの尤度を最大化できるわけです。これが VAE の中核的なアイデアなのです。

■ スライド 9／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（学習アルゴリズム・損失関数）
----------------------------------------

では、変分オートエンコーダーの実装における学習アルゴリズムを説明します。

訓練データの各データ点 x_i に対して、次の損失関数を計算します：

ℓ(θ,ψ,x) = E_{z~Enc_ψ(x)}[-log N(g_θ(z),I)(x)] + KL(Enc_ψ(x) ‖ p(z))

この式の各部分を説明します。

**第一項：再構成誤差**

E_{z~Enc_ψ(x)}[-log N(g_θ(z),I)(x)]

ここで、Enc_ψ(x) は、エンコーダーがデータ x から出力する潜在変数分布です。この分布からサンプリングした z に対して、生成器 g_θ(z) が平均で、単位分散を持つ正規分布から、データ x が生成される確率の対数を計算します。言い換えると、生成器が元のデータをどの程度よく再構成できるかを表しています。

**第二項：正則化項**

KL(Enc_ψ(x) ‖ p(z))

ここで、事後分布の近似結果が、事前分布 p(z) から離れすぎないように調整されます。

実際の実装では、例えば次のようなモデルを使うことが多いです：

Enc_ψ(x) = N(m_ψ(x), Σ_ψ(x))
p(z) = N(0, I)

両者とも正規分布なので、KL ダイバージェンスは解析的に計算可能です。その公式は次の通りです：

KL(N(m,Σ) ‖ N(0,I)) = ½(tr(Σ) + m^T m - d - log det(Σ))

ここで d は潜在次元数、tr(Σ) は Σ の対角成分の和（トレース）、det(Σ) は Σ の行列式です。

この公式があれば、KL ダイバージェンスの値を直接計算でき、勾配計算も容易です。

■ スライド 10／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（再構成誤差の計算）
----------------------------------------

再構成誤差の計算方法について、より詳しく説明します。

再構成誤差の部分は：

E_{z~Enc_ψ(x)}[-log N(g_θ(z),I)(x)]

この期待値の計算は、次のステップで行われます。

**1. エンコーディング**

入力データ x をエンコーダーに入力します。エンコーダーは、近似事後分布の平均 m_ψ(x) と分散 Σ_ψ(x) を出力します。

**2. サンプリング**

この分布からサンプル z を複数個取得します。通常は数個から数十個のサンプルを使用します。

**3. デコーディング**

各サンプル z に対して、生成器に通します。生成器 g_θ(z) は、復元されたデータ x_reconstructed を出力します。

**4. 尤度計算**

各サンプルに対して、-log N(g_θ(z),I)(x) を計算します。これは、生成器の出力を平均とする正規分布のもとで、元のデータ x の対数尤度の符号を反転したものです。

**5. 平均**

計算した値の平均をとることで、期待値の近似値を得ます。

このプロセスにより、確率的な期待値を実際に計算することができるのです。

■ スライド 11／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（微分の問題）
----------------------------------------

さて、ここまで損失関数の計算方法を説明してきました。しかし、ニューラルネットワークの学習には、この損失を各パラメーターで微分する必要があります。ここに重要な問題が生じます。

期待値の部分にパラメーター ψ や θ が含まれています。より具体的には、計算グラフの途中に、潜在変数 z のサンプリングが含まれています。

計算グラフを図示すると、次のようになります：

φ, x → (m, σ²) → [サンプリング（?）] → z → g → L

ここで、「[サンプリング（?）]」の部分が微分不可能な操作です。

ランダムに z をサンプリングする操作は、決定的ではないため、通常の微分ルール（連鎖律）を適用することができません。これが、VAEの学習における大きな課題です。

この問題を解決するために、次のスライドで説明する「再パラメータ化トリック」という重要なテクニックが必要になるのです。

■ スライド 12／12：生成タスク ＞ 潜在変数型の生成 ＞ VAEs
（再パラメータ化トリック）
----------------------------------------

「再パラメータ化トリック」（reparameterization trick）は、VAEの学習を可能にする最も重要なテクニックです。

基本的なアイデアは、エンコーダーを特定の構造に限定するということです。エンコーダーを次のような形にします：

Enc_ψ(x) = N(m_ψ(x), diag(σ²_ψ(x)))

つまり、平均 m_ψ(x) と対角共分散行列 diag(σ²_ψ(x)) を持つ正規分布です。

この設定の下で、潜在変数 z をサンプリングする際に、次の変換を使用します。

別の変数 ε を標準正規分布 N(0,I) からサンプリングして、次のように z を生成します：

z := m_ψ(x) + exp(½ log σ²_ψ(x)) ⊙ ε

ここで ⊙ は要素ごとの積（アダマール積）です。exp(½ log σ²_ψ(x)) は、正の標準偏差 σ_ψ(x) に相当します。

**このトリックの意義は何でしょうか？**

このように書き直すことで、確率的な要素は ε の部分だけになります。m_ψ(x) と σ_ψ(x) はニューラルネットワークの出力で、パラメーター ψ に関して決定的です。したがって、m_ψ(x) と σ_ψ(x) に対する勾配は、通常の微分（連鎖律）で計算できるようになります。

修正後の計算グラフは以下のようになります：

φ, x → (m, σ²) → z = m + σ⊙ε ← ε~N(0,I)

ここで、ε~N(0,I) は計算グラフの外側に出ているため、微分の対象ではありません。一方、m と σ に対しては正常に勾配を計算できます。

つまり、「ランダムサンプリング」を計算グラフから切り離すことで、確定的な計算グラフを作成し、誤差逆伝播（backpropagation）で勾配計算を可能にするのです。

これが、VAEが実装可能な理由であり、変分推定を深層ニューラルネットワークと組み合わせるための鍵となるテクニックなのです。
