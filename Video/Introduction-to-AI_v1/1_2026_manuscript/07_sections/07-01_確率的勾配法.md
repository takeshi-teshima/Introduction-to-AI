# [06: Slide 1/14] ニューラルネットワークの最適化① 確率的勾配法

前回の講義ではニューラルネットワークというモデルの構造について学びました．
ここからは，ニューラルネットがデータに適合するように，そのパラメータ（重みやバイアス）を自動的に調整する「最適化（学習）」についてお話ししていきます．まずは「確率的勾配法」を取り上げます．

# [06: Slide 2/14] ニューラルネットの最適化の概要

ニューラルネットワークは構造の自由度などから非常に有力なモデルの一つですが，パラメータが複雑に絡み合うので，最適化には独自の工夫が凝らされています．
本ユニットでは，ニューラルネットワークの最適化における基本となる「確率的勾配法」と，次回扱う「誤差逆伝播」の [2](ふた)つの考え方を中心に解説していきます．

# [06: Slide 3/14] 取扱いの難点①：データの大規模化

ニューラルネットワークの最適化における難点の [1](ひと)つ目として，データが大規模になりがちであるという問題があります．
複雑なデータに対応するために，ニューラルネットワークのパラメータ数は大規模になります．パラメータ数が多いので，訓練データも大規模にしないと性能が良くならないためです．
インターネット時代の到来により，例えば 2009 年の ImageNet では数百万枚の画像が，2023 年の言語モデルのデータでは数千億単語以上のデータが収集され，用いられるようになっています．

# [06: Slide 4/14] 基本的なアプローチ：勾配法

このように複雑なモデルに対して，基本的には大域的最適解を求めるような解の公式はないので，以前学んだような「勾配法」をベースにして最適化を行います．
ただし，ニューラルネットワークの性質に合わせて，経験則や理論解析に基づく様々な工夫が取り込まれています．
単なる勾配降下法ではなく，かなり複雑な最適化手法が発達しており，こうした最適化手法に取り入れる工夫も，モデルの帰納バイアスの一端を担うことになります．

# [06: Slide 5/14] 大規模化への対応：計算量の問題

ここで，データが大規模になった時の問題点を見ていきましょう．
機械学習の基本方針である「経験リスク最小化」では，すべてのデータに対する損失の平均値を計算し，その勾配をもとにパラメータを更新します．
しかし，例えばデータが [10](じゅう)億件あるとすると，[1](いち)回の更新をするだけでも [10](じゅう)億件分の勾配計算が必要になります．
あまりにデータが多い場合，そもそもコンピューター [1](いち)台には入りきらず，実行不可能になってしまいます．これが，訓練時の計算量を制御する工夫が必要となる理由です．

# [06: Slide 6/14] リスクのサンプル近似とミニバッチ

この計算量の問題を解決するためのアプローチが，「ミニバッチ確率的最適化（[Mini-batch Stochastic Optimization](ミニ・バッチ・ストカスティック・オプティマイゼーション)）」です．

このアプローチの根本的な考え方は，「リスクをサンプル近似するために，わざわざ手元のデータすべてを毎回使う必要はない」という統計的な割り切りにあります．
毎ステップ，データ全体から例えば [32](さんじゅうに)個や [64](ろくじゅうよん)個といった小さなデータのサブセットを「ミニバッチ」として取得し，この一部のデータだけを用いて暫定的な損失とその勾配を計算し，学習を進めます．
これが統計的な「確率的近似」です．名前に「確率的（[stochastic](ストカスティック)）」とついているのは，このミニバッチを毎回ランダムに選ぶことに由来しています．

このミニバッチに含まれるデータ数を「バッチサイズ」と呼び，[1](いち)件から数百件程度に設定します．
通常のミニバッチの作り方としては，訓練データをシャッフルし，バッチサイズごとに分割しておく，という方法がよく用いられます．

続いて，あらかじめ分割しておいた各ミニバッチ [B](ビー) を順に処理し，その中に含まれるデータだけで算出した勾配を使い，パラメータ [θ](シータ) を少しだけ（学習率 [η](イータ) を掛けて）勾配の反対方向に更新します．
全データを [1](いち)周分処理し終えることを「[1](いち)エポック（[epoch](エポック)）」と呼び，実用上は何十・何百エポックとこのループを必要なだけ繰り返して学習を進めます．
そして，早期停止条件を満たしたところで中断し，最終的なパラメータを使用します．

# [06: Slide 8/14] 勾配法における設定項目

通常の勾配法に加えて，ミニバッチ確率的勾配法を実際に使う際には，さらにいくつか決めるべき項目があります．
例えば，全体で「何エポック学習するか」，ミニバッチの「バッチサイズをいくつにするか」，そして「エポック毎にデータをシャッフルしてミニバッチの再分割をするか」といった項目です．
これらは学習の効率などに影響を与えます．

# [06: Slide 9/14] 取扱いの難点②：目的関数の非凸性

続いて，最適化における難点の [2](ふた)つ目，「目的関数の地形が複雑である」ことについてお話しします．
これまで扱ってきた線型モデルの最小二乗法などでは，目的関数の地形が綺麗な「凸最適化問題」であったため，大雑把に言って解は [1](ひと)つで，見つけやすい性質がありました．
しかし，ニューラルネットワークのような非凸最適化問題では，局所的最適解が多数存在し，大域的最適解を求めるのが困難になります．目的関数の「地形」が複雑で，単純に坂を下るだけでは駄目かもしれない，というのが大きな課題です．

# [06: Slide 10/14] 局所的最適化手法の限界

勾配法による最適化は，基本的に「今いる場所の情報」だけでパラメータを更新する局所的最適化手法です．

# [06: Slide 11/14] 局所的最適解へのスタック

そのため，本当はもっと損失値が低い場所へ移動したいのに，目の前の勾配に従って左に動いてしまい，浅い谷である局所的最適解に落ち込んでしまうことがあります．
このように，大域的な地形を踏まえた移動は基本的に難しいのが実情です．

# [06: Slide 12/14] 複雑な構造を想定した工夫

そこで実際には単純な勾配法ではなく，色々な工夫を組み込んだ最適化法が使われます．
例えば，学習率の調整や，物理の「慣性（モメンタム）」を更新則に組み込むなどの工夫です．
代表的なものに Adam（アダム）などがあり，様々な最適化手法が提案されています．

# [06: Slide 13/14] まとめ

ここまでのまとめです．
ニューラルネットワークの最適化は，データ量が大規模であることや，目的関数の地形が複雑で局所的最適解が存在するといった主な複雑さがあります．
これに対する解決方針として，確率的勾配法により [1](いち)度に全データを扱わなくてよいようにすること，そして局所的最適解を避けるための様々な工夫を凝らした最適化手法を用いることが挙げられます．
実用上は，その時点で評判が良い手法を選ぶのが一般的です．
