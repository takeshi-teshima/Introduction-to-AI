# [ID: Slide 29/92] 誤差逆伝播法
今回は，前回のミニバッチ [SGD](エス・ジー・ディー) で必要となる各パラメータの勾配（偏微分）を，コンピュータでシステマチックかつ超高速に計算する手法「誤差逆伝播法（[Backpropagation](バックプロパゲーション)）」について説明します．

# [ID: Slide 30/92] 本ユニットの目的
前回の講義の最後で，ミニバッチ [SGD](エス・ジー・ディー) の枠組み自体は理解できたものの，何重にも重なった合成関数の勾配をどう効率的に求めるかという問題が残っていました．
今回はその答えを解き明かしていきます．

# [ID: Slide 31/92] 解析的微分の限界
まず，パラメータの勾配を「手計算で」求めようとするとどうなるか，考えてみましょう．

パラメータの勾配を手計算で数学的な数式として展開し（解析的に求め），それをそのままプログラムに書き込もうとすると，関数の入れ子構造があまりにも深いため，数式の記述が複雑になりすぎて人間には不可能な領域に達してしまいます．
何十層もあるネットワークのすべてのパラメータに対する偏微分を一つ一つ手で導出するのは，現実的に不可能です．

# [ID: Slide 32/92] システマチックな勾配計算の存在
人間が手で偏微分の式を書き下すのは不可能です．
しかし，実は，どれほど巨大なニューラルネットワークであっても，コンピュータを用いて機械的に，そして完璧にシステマチックに勾配を計算できる魔法のような方法が存在します．

スライドの左側には巨大なネットワーク図を，右側にはそこから得られる勾配ベクトルの式を示しています．
これほど複雑な構造であっても，すべてのパラメータの勾配を一挙に，しかも高速に求める方法があるのです．

# [ID: Slide 33/92] 自動微分の導入
その方法は「自動微分（[Automatic differentiation](オートマティック・ディファレンシエーション)）」と呼ばれています．
数式そのものを展開するのではなく，各計算ステップの局所的な傾きだけを順に掛け合わせることで，全体の微分を求めるアプローチです．

ニューラルネットの分野では，これを「誤差逆伝播法（[Backpropagation](バックプロパゲーション)）」と呼びます．
実はこの仕組みは，高校数学で習う「連鎖律（チェインルール）」を詳しく見ることによって作られています．
仕組みを知るために，まず連鎖律が何だったかを思い出してみましょう．

# [ID: Slide 34/92] 連鎖律の2つの計算アプローチ
合成関数の微分を求めるには，[2](ふた)つのアプローチがあります．

[1](ひと)つ目は，合成関数としてすべて「展開してから微分する」方法です．
[2](ふた)つ目は，個々の「局所的な微分をあらかじめ計算しておいて，後から積（掛け算）を計算する」方法です．

力任せ（[Brute-force](ブルートフォース)）でやろうと思ったら前者ですが，計算量は爆発してしまいます．
一方，後者の「局所的な微分の積を求める」という連鎖律の性質をうまく活かすと，劇的に計算を整理できます．

# [ID: Slide 35/92] ニューラルネットワークの連鎖構造と連鎖律
なぜこの連鎖律のアプローチがディープラーニングで重要なのでしょうか．

それは，ニューラルネットワークが「あるユニットの出力が次のユニットに渡されて入力になり，それが何層にもわたって連なっている構造」をしているからです．
この連鎖構造そのものが，まさに「局所的な微分の積」を順番にバケツリレーしていく計算方法に完璧に適合しているのです．
これによって，システマチックな微分計算が可能になります．

# [ID: Slide 36/92] 計算グラフとDAGの概念
これをコンピュータで処理しやすくするため，まずはユニットのつながり方を「計算グラフ（[Computational Graph](コンピューテーショナル・グラフ)）」として表現します．

計算グラフとは，入力データやパラメータ，そして途中で発生する中間変数などが，どのような数式関係で結ばれているのかを，丸（変数やノード）と矢印（計算の依存関係を示すエッジ）で表したネットワーク図のことです．
これは情報科学における「有向非巡回グラフ（[DAG](ディーエージー)）」であり，循環（ループ）がないため，計算順序が一意に決まります．

# [ID: Slide 37/92] シンプルな1次元モデルの計算グラフ
さて，仕組みを理解するために，まずは非常にシンプルな [1](いち)層・[1](いち)次元のニューラルネットワークを具体例として，実際に計算を追ってみましょう．

数式では，[s = wx + b](エス・イコール・ダブル・エックス・たす・ビー) を計算し，活性化関数 [σ](シグマ) に通して出力 [g](ジー) を得て，そこから二乗損失 [L = (g - y)^2](エル・イコール・かっこ・ジー・マイナス・ワイ・かっこ・にじょう) を計算します．
これを計算グラフとして表すと，スライドのように各足し算や掛け算，関数適用が順に繋がった一本の鎖のようなグラフになります．

# [ID: Slide 38/92] 計算グラフにおける順伝播
ニューラルネットに入力をすると，どう出力値が計算されていたかというと，まず現在のパラメータ値と入力データという具体的な数値を左から右へと流していきます．

例えば [w = 3, b = 1, x = 2, y = 5](ダブル・イコール・さん、ビー・イコール・いち、エックス・イコール・に、ワイ・イコール・ご) とすると，まず中間変数 [s = wx + b = 3 × 2 + 1 = 7](エス・イコール・ダブル・エックス・たす・ビー・イコール・なな) が決まります．
次に，出力 [g = σ(7)](ジー・イコール・シグマ・なな) はシグモイド値として計算されます．
最終的に損失 [L = (g - 5)^2](エル・イコール・かっこ・ジー・マイナス・ご・かっこ・にじょう) が具体的な数値として求まります．
このように，すべての中間変数の値を順番に計算してメモリに記録していく流れを「順伝播（[forward propagation](フォワード・プロパゲーション)）」と呼びます．

# [ID: Slide 38/92] 計算グラフの微分と連鎖律の原則
続いて，この計算グラフの微分を考えていきましょう．

連鎖律で微分を計算するのはこういうことでした．
つまり，出力側から順番に微分を計算して遡って，それを掛け算すればいいですね．

ただしその際に，各ユニットの微分は「現在の値」を使うので，入力から一度順伝播しておいて，その時の値を覚えておいて，微分に代入して，掛け算するんですね．

これが，先ほど順伝播で中間変数の値をメモリに記録しておいた理由です．

# [ID: Slide 38/92] 逆方向への遡りと局所的な微分の掛け算
では，実際に遡ってみましょう．
順伝播で値が確定しているので，一番右端の損失 [L](エル) から左（入力側）へと遡っていきます．
各ノードは，右から受け取った微分値に，自身の「局所的な微分（偏微分）」を掛け合わせて左へと伝えます．

# [ID: Slide 38/92] 連鎖律による偏微分の計算例
例えば，パラメータ [w](ダブル) に対する損失の偏微分 [[ \frac{\partial L}{\partial w} ]](ラウンド・エル、ラウンド・ダブル) を求めたいとします．
微分の連鎖律によると，この値は [[ \frac{\partial L}{\partial g} \cdot \frac{\partial g}{\partial s} \cdot \frac{\partial s}{\partial w} ]](ラウンド・エル・ラウンド・ジー、かける、ラウンド・ジー・ラウンド・エス、かける、ラウンド・エス・ラウンド・ダブル) という，途中の局所的な偏微分の掛け算として表すことができます．
それぞれのノードの計算式は非常にシンプルなので，個別の偏微分は簡単に求まります．

# [ID: Slide 38/92] 自動微分によるプロセス
この逆方向のバケツリレーのような掛け算の繰り返しで，先ほど確認した「個別の微分を計算して積を求める」という連鎖律のプロセスが，グラフ上で自動的に実行されます．
これを「自動微分（[Automatic differentiation](オートマティック・ディファレンシエーション)）」と呼びます．

# [ID: Slide 38/92] 順伝播の値を再利用した効率的な微分計算
逆伝播の計算効率は圧倒的です．
例えばシグモイド関数の微分 [σ'(s)](シグマ・プライム・エス) は，順伝播で計算した出力 [g = σ(s)](ジー・イコール・シグマ・エス) を用いて [g(1 - g)](ジー・かっこ・いち・マイナス・ジー・かっこ) と極めて簡単に再利用できます．
わざわざ微分の式を一から計算し直す必要がないのです．

# [ID: Slide 38/92] 誤差逆伝播法のまとめと意義
これによって，どんなに深いネットワークであっても，順伝播とほぼ同じ非常に小さな計算量ですべてのパラメータの勾配を同時に計算できます．
頭を悩ませて全体の複雑な微分方程式を解くことなく，プログラムによって完全に機械的に，しかも高速に勾配を算出することができるのです．
この誤差逆伝播法の恩恵によって，あらゆるアーキテクチャのニューラルネットワークが勾配法によって統一的に学習可能になりました．

# [ID: Slide 39/92] 実験タスク：5クラス分類問題
これまでに学んだモデル構造，ミニバッチ [SGD](エス・ジー・ディー)，誤差逆伝播法の組み合わせで，実際に複雑な問題が解けるか実験してみましょう．

タスクとして，スライドのように，[2](に)次元平面上に [5](ご)つの異なる色のデータが固まって分布している「[5](ご)クラス分類問題」を考えます．
クラス同士の境界がかなり複雑に入り組んでおり，単純な直線（線型モデル）では分類できないデータ分布です．

# [ID: Slide 40/92] 実験のモデル構造設定
この問題に対し，次のようなモデルと設定を用意して学習させます．
モデル構造としては，[3](さん)層の順伝播型全結合ネットワークを使用します．
入力次元は [2](に)次元で，これはデータの座標 [x_1, x_2](エックス・いち、エックス・に) に対応します．
第 [1](いち)隠れ層の幅は [64](ろくじゅうよん)ユニットとし，活性化関数には [ReLU](レルー) を使います．
第 [2](に)隠れ層の幅は [32](さんじゅうに)ユニットで，こちらも活性化関数は [ReLU](レルー) です．
出力層の次元は [5](ご)次元とし，活性化関数にソフトマックス関数を適用して，[5](ご)クラスの確率値を出力するようにします．

# [ID: Slide 40/92] 実験の目的関数と最適化設定
目的関数には，多クラスの負の対数尤度，つまり交差エントロピー誤差の平均値を使用します．
最適化アルゴリズムには [Adam](アダム) を使用し，学習率は [10^{-3}](じゅうのマイナスさんじょう)，バッチサイズは [32](さんじゅうに)に設定し，最大 [100](ひゃく)エポック学習を行います．

# [ID: Slide 41/92] 学習の進行（損失の減少）
それでは，学習がどのように進行していったか，その結果をビジュアルで確認してみましょう．

スライド中央のグラフは，最適化のステップ数（横軸）に伴って，訓練データ上の損失関数（縦軸）が減少していく様子を示しています．
学習が進むと，損失関数の値はステップを追うごとに綺麗に減少していきます．

# [ID: Slide 41/92] 非線形な決定境界の形成
左側の「訓練前の予測器」の図では，色分けされた境界がデータの実際の分布と全く無関係にランダムな境界を描いていますが，学習を終えると，[5](ご)つのクラスの境界を綺麗に捉えた滑らかな「非線形な決定境界」が自動的に形成されているのが見て取れます．

# [ID: Slide 42-43/92] 第6回・第7回の総括
今回の全体の総括です．
ニューラルネットワークは，層を重ねて複雑な関数を表す高い「表現力」，大規模データでもパラメータを更新できる「ミニバッチ [SGD](エス・ジー・ディー)」，そして速度と効率に優れる「誤差逆伝播法」という [3](みっ)つの技術が噛み合うことで機能しています．
このように，非凸という最適化の難しさを抱えながらも，自動微分による効率的な勾配計算と，確率的最適化アルゴリズムの組み合わせによって，ニューラルネットワークは極めて複雑なデータ分布パターンを強力に学習することができるのです．

# [ID: Slide 72/92] なぜ順伝播で中間値を保持する必要があるのか【補足】
ここで，[1](ひと)つ発展的な補足をしておきます．

「微分を求めたいだけなのに，なぜ最初にわざわざ順伝播で具体的な数値を計算するのか？」という疑問についてです．

理由は，偏微分の具体的な数値を計算するには，そのノードにおける変数（例えば [s](エス) や [g](ジー)）の具体的な値が式に代入されなければならないからです．
例えば，シグモイド関数の微分は [σ'(s) = g(1 - g)](シグマ・プライム・エス・イコール・ジー・かっこ・いち・マイナス・ジー・かっこ) でしたが，この値を実際に計算するためには，[g](ジー) の値（つまり順伝播での [σ(s)](シグマ・エス) の計算結果）が具体的な数字として確定していなければなりません．
同じように，損失の微分 [2(g - y)](に・かっこ・ジー・マイナス・ワイ・かっこ) を計算するにも，出力 [g](ジー) の値が必要です．

このように，現在の各ノードでの値を確定させておくために，まず順伝播の値をメモリに保持しておく必要があるのです．
