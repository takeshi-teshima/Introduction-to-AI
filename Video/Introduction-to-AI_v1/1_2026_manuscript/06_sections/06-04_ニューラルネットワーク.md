# [06: Slide 1/24] ニューラルネットワーク
ここからは，ニューラルネットワークについて説明していきます．
これは最近話題のディープラーニング（深層学習）の基礎となる，非常に重要なモデルです．

現在，実用的に広く使われており，性能が高いと言われているモデルの多くが，このニューラルネットワークと呼ばれる種類のモデルになっています．
例えば，皆さんもよく知っているチャット[GPT](ジーピーティー)などの高度な機械学習モデルも，モデルとしては「[GPT](ジーピーティー)」というタイプのニューラルネットワークで作られています．
このニューラルネットワークがどういう学習の仕組みになっているかが分かっていると，ここまでの線形モデルで話してきた内容と最近の高度なモデルがどういう風にできているのかという話がつながり始めて，裏の仕組みがイメージしやすくなるかなと思います．

# [06: Slide 2/24] ニューラルネットワークの概要
ニューラルネットワークは非常に柔軟な非線形モデルで，画像認識や自然言語処理など，現代の高度な機械学習の多くで中心的な役割を果たしています．
例えばチャット[GPT](ジーピーティー)などのモデルも，この仕組みの発展形で作られています．
本節では，まずそのモデル構造から学んでいきましょう．

# [06: Slide 3/24] 変換の階層性
このニューラルネットというモデルでお話ししていく中で，一番最初に押さえておきたいポイントは「変換の階層性」というところにあります．

これまで扱ってきた線形モデルの構造を思い出していただくと，入力 [x](エックス) を受け取って，特徴量変換 [φ(x)](ファイ・エックス) で変換し，出てきたベクトルにパラメータ [θ](シータ) をかけて内積 [[θ^T φ(x)]](シータ・てんち・ファイ・エックス) を計算して出力する，という構造になっていました．
このとき，学習によって調整可能なパラメータは [θ](シータ) であり，これは最終的な出力値の直前の一箇所だけに関与していました．
つまり調整できるのは最後だけです．

それに対してニューラルネットワークでは，パラメータが関与する箇所が最後の一箇所だけではなく，途中の変換プロセス自体にも何段階にもわたってパラメータを埋め込んでいきます．
入力 [x](エックス) を受け取ると，パラメータがついている変換をかけて，さらにパラメータがついている変換をかけて，というように何度も変換を繰り返して最終的な出力が決まります．
これが「変換の階層性」です．

# [06: Slide 4/24] 順伝播型ニューラルネットワーク
ニューラルネットに分類されるモデルはいろいろな形のものがありますが，その中で最も基本的な構造から説明していきます．
それが「順伝播型ニューラルネットワーク（[Feedforward Neural Network](フィードフォワード・ニューラル・ネットワーク)）」と呼ばれるものです．

これは「レイヤー（層）」と呼ばれる部品を直列につなげて複雑な関数を作るモデルになっています．
入力を受け取ってから，複数のレイヤーを直列に繋ぎ，出力を得ます．
レイヤーの位置によって，最初を入力に近い「入力層（[Input layer](インプット・レイヤー)）」，中間を「中間層（[Intermediate layer](インターミディエイト・レイヤー)）」または「隠れ層（[Hidden layer](ヒドゥン・レイヤー)）」と呼び，最後を「出力層（[Output layer](アウトプット・レイヤー)）」と呼びます．

# [06: Slide 5/24] ノーテーションの注意
講義の本題に入る前に，これから多次元のベクトル出力を組み立てていく上で，数式をすっきりと書くための記号のルールを一つ導入しておきます．

通常，[ψ](プサイ) のような関数は，一つの実数を受け取って一つの実数を出力する「一変数関数」として定義されます．
しかし，これからニューラルネットワークの数式を扱う中では，特に断りがない限り，この一変数関数 [ψ](プサイ) に「多次元ベクトル」を直接代入できることとします．

具体的には，ベクトル [a = [a_1, a_2, \dots, a_d]^T](エー・イコール・エー・いち、エー・に、てんてんてん、エー・ディーのてんちベクトル) が入力されたとき，[ψ(a)](プサイ・エー) と書けば，それはベクトルの「各成分ごとに個別に関数 [ψ](プサイ) を適用した新しいベクトル」，すなわち [[ψ(a_1), ψ(a_2), \dots, ψ(a_d)]^T](プサイ・エー・いち、プサイ・エー・に、てんてんてん、プサイ・エー・ディーのてんちベクトル) を表すものと定義します．
この表記方法を用いることで，層ごとの多次元な変換計算を非常にシンプルに表現できるようになります．

# [06: Slide 6/24] レイヤーの構成要素（変換数式）
それでは，個々のレイヤーが内部で具体的にどのような計算を行っているのか，その数式と処理の流れを見ていきましょう．

一つのレイヤーに入力されるベクトルを [x](エックス) としたとき，レイヤーが行う計算は，「線形変換」と「活性化関数の適用」の二つのステップに分かれます．
まず，入力 [x](エックス) に対して，パラメータである重み行列 [W](ダブル) を掛け算し，さらにパラメータであるバイアスベクトル [b](ビー) を足し合わせます．
この [Wx + b](ダブル・エックス・たす・ビー) という計算は，アフィン変換と呼ばれる「線形変換（[linear transformation](リニア・トランスフォーメーション)）」です．
この計算で得られた中間のベクトルを，一旦 [u](ユー) と置くことにします．

次に，この中間ベクトル [u](ユー) のすべての成分に対して，一変数関数 [ψ](プサイ) を適用します．
この関数 [ψ](プサイ) のことを「活性化関数（[activation function](アクティベーション・ファンクション)）」と呼び，この関数を通した最終的な出力 [ψ(u)](プサイ・ユー) が，このレイヤーの出力値となります．
このように，「重みをかけてバイアスを足し，活性化関数に通す」という比較的シンプルな処理が，各レイヤーの中身です．

# [06: Slide 7/24] 活性化関数の種類
活性化関数 [ψ](プサイ) には，モデルの性質に応じて様々な非線形関数が選ばれます．ここで代表的なものを紹介します．

まず，[2](に)値分類のロジスティック回帰でも登場した [S](エス)字型の「シグモイド関数（[Sigmoid function](シグモイド・ファンクション)）」があります．
次に，現在最も標準的に使われている「[ReLU](レルー)関数（[Rectified Linear Unit](レクティファイド・リニア・ユニット)）」があります．これは数式では [\\max(0, u)](マックス・ぜろ、ユー) と表され，入力が正ならそのまま，負なら [0](ぜろ) を出力します．非常に計算が軽いという大きなメリットがあります．
また，「[Leaky ReLU](リーキー・レルー)」や「[Swish](スウィッシュ)」と呼ばれる，[ReLU](レルー) の欠点を補うために提案された，負の領域でもわずかに傾きを持つような派生形も非常によく用いられます．
最後に，入力をそのまま出力する恒等関数である「リニアアクティベーション」があります．主に回帰タスクの出力層で使用されます．

# [06: Slide 8/24] レイヤーの重ね合わせ
個々のレイヤーが行う計算は比較的シンプルなものでしたが，これらをたくさん直列に重ね合わせることで，全体として複雑な関数を表現することができます．

例として，[3](さん)層構造のニューラルネットワークの計算式を見てみましょう．
入力 [x](エックス) に対し，第 [1](いち)層では重み [W_1](ダブル・いち) とバイアス [b_1](ビー・いち) による線形変換と活性化関数 [ψ_1](プサイ・いち) による変換が行われます．
この出力が次の層に入力され，重み [W_2](ダブル・に)，バイアス [b_2](ビー・に)，活性化関数 [ψ_2](プサイ・に) による変換が適用されます．
さらにその出力が次の層に入力され，重み [W_3](ダブル・さん)，[b_3](ビー・さん)，活性化関数 [ψ_3](プサイ・さん) によって最終出力が決まります．

# [06: Slide 9/24] レイヤーの重ね合わせ（合成関数）
数式で書くと，前のレイヤーの出力を次のレイヤーの入力として順次渡していくため，全体としては関数が何重にも入れ子になった「合成関数」の形になります．
層を重ねるごとに表現できる関数が複雑になります．

# [06: Slide 10/24] パラメータの形状制約
ニューラルネットワークを正しく設計するためには，各層の間でベクトルの次元数がきれいに一致するように，パラメータ（重み行列 [W](ダブル) とバイアスベクトル [b](ビー)）の「サイズ（形状）」を整合させる必要があります．

例えば，前の層の出力が [d](ディー) 次元で，現在の層の出力を [r](アール) 次元にしたいとします．
このとき，重み行列 [W](ダブル) のサイズは必ず「[r × d](アール・かける・ディー)」の行列でなければなりません．
バイアスベクトル [b](ビー) も [r](アール) 次元のベクトルである必要があります．
次元のパズルを合わせるイメージです．

間の隠れ層で何次元にするか（ユニット数）はハイパーパラメータとして自由に選ぶことができますが，最初と最後の次元はデータの形やタスクで制限を受けることになります．

# [06: Slide 11/24] 出力層の活性化関数選択
中間層における活性化関数や次元数は自由に設計できますが，最終的な「出力層」の活性化関数と出力次元だけは，解きたいタスクの要件に応じて適切に選ぶ必要があります．

まず，回帰タスクを解きたい場合は，出力値は実数全体であってほしいため，範囲の制限がない「リニアアクティベーション（恒等写像）」を選択します．この場合の出力次元は，予測したい数値の個数（通常は [1](いち)次元）にします．
次に，[2](に)クラスの確率論的分類を行いたい場合は，出力は正解クラスである確率，すなわち [0](ぜろ) から [1](いち) の間の実数にする必要があるため，「シグモイド関数」を選択します．この場合の出力次元は [1](いち)次元です．
そして，多クラスの確率論的分類を行いたい場合は，すべてのクラスに対する確率値ベクトル，つまり足し合わせると [1](いち) になるようなベクトルを得たいため，出力層には「ソフトマックス関数」を適用します．

# [06: Slide 12/24] ユニットの概念
ここまでは，ニューラルネットワークを「ベクトルを変換するレイヤー（層）の積み重ね」というマクロな視点で見てきました．
ここからは中身をさらに細かく見てみましょう．実は各レイヤーは，並列に計算を行う「ユニット（素子）」と呼ばれる小さな部品の集まりとみなせます．
スライドのように，マクロな「レイヤー表現」は，ミクロな「ユニット表現」へと対応づけることができます．

# [06: Slide 13/24] レイヤーとユニットの両方の視点が必要な理由
ここで少し，なぜこの [2](ふた)つの視点が必要なのかについてお話ししておきます．
マクロな「レイヤー視点」は，数式をすっきり書き，コンピュータで行列計算を高速化するために使います．実際のプログラミングもレイヤー単位で行います．
一方，ミクロな「ユニット視点」は，情報がどう流れるかを視覚的に理解し，接続パターン（アーキテクチャ）を柔軟に設計するために不可欠です．
また，後で学ぶ「自動微分」の仕組みを理解する上でも，このミクロな視点が大きな鍵になります．

# [06: Slide 14/24] ユニットの数学的な定義
レイヤーの計算 [u = ψ(Wx + b)](ユー・イコール・プサイ・ダブル・エックス・たす・ビー) を成分ごとに分解してみましょう．

重み行列 [W](ダブル) の各行を横ベクトル [w_1^T, w_2^T, \dots, w_r^T](ダブル・いち・てんち、ダブル・に・てんち、てんてんてん、ダブル・アール・てんち) に分解してみます．
すると，このレイヤーの出力ベクトルの第 [i](アイ) 成分は，数式で書くと [ψ(w_i^T x + b_i)](プサイ・ダブル・アイ・てんち・エックス・たす・ビー・アイ) と表されます．
この，出力の各 [1](いち)次元（各成分）を計算している個々の仕組みを「ユニット（[unit](ユニット)）」と呼びます．
なお，入力データの各次元（[x_1, x_2](エックス・いち、エックス・に) など）を保持する一番左の丸を「入力ユニット」と呼びます．

# [06: Slide 15/24] ユニットの図式ルール
ユニットの視点を取り入れると，ニューラルネットワークの複雑な構造を，丸と線を用いたグラフィカルな図（ネットワーク図）で表すことができるようになります．

この図式では，次のようなルールで構成されます．
まず「丸（ノード）」は，各ユニットの値（変数）を表しています．
次に「矢印（エッジ）」は，そこを流れる値に掛ける重み [w_{ij}](ダブル・アイ・ジェー) を表しています．
各ユニットは，自分に向かって入ってくるすべての線の値を，それぞれの重みを掛けて合計し，さらに自身のバイアス [b](ビー) を足して活性化関数に通した値を，自身の「丸の値」として保持します．
重みが [0](ぜろ)（繋がっていない）の箇所は矢印を描きません．

# [06: Slide 16/24] ユニットにおける値の流れ（値の伝播）
この丸と線の図式を使って，ネットワーク全体を可視化してみましょう．

このルールに基づいて計算の流れを追ってみます．まず入力データが入ると，一番左の入力ユニットの値が決まります．
これが矢印に沿って重みを掛け合わされながら中間層のユニットへと伝わり，さらに次の層へと順番にドミノ倒しのように伝わって，最終的な出力が得られます．
これが値の「順伝播（[forward propagation](フォワード・プロパゲーション)）」のイメージです．

# [06: Slide 17/24] レイヤーの幅と深さ
中間層のユニット数を「幅（[width](ウィズ)）」，層の数を「深さ（[depth](デプス)）」と呼びます．

スライドの図は，パラメータをランダムに選んで，順番に層を増やしていったものです．
一番左の「真ん中に [1](いっ)層」しかない場合はかなり簡単な関数になっていて，ほとんど平面のような形をしています．
しかし，「[10](じゅう)層」ある場合は，適当にパラメータを決めていても結構折りたたまれたような出力曲面になります．
さらに「[15](じゅうご)層」になると，曲面はかなりギザギザした複雑な形になってきます．

# [06: Slide 18/24] 表現能力と深層学習
層を増やす（深くする）ことで，ネットワーク全体としては非常に複雑に折りたたまれた曲面（関数）を表現できるようになります．
これが深層ネットワークの高い表現力の源泉です．この幅と深さを大きく設計したネットワークを学習させることを「深層学習（ディープラーニング）」と呼びます．

# [06: Slide 19/24] 接続の自由度（全結合層）
ユニットの繋ぎ方は本来自由です．
前の層のすべてのユニットから次の層のすべてのユニットへ漏れなく線が繋がっている構造を，特に「全結合層（[Fully Connected Layer](フリー・コネクティッド・レイヤー)）」と呼びます．
これは，これまでに説明してきた行列の掛け算をそのまま実行していることに相当します．

# [06: Slide 20/24] 接続の自由度（部分的な接続）
また、全結合層だけでなく、あえて一部の接続をなくし（重みを [0](ぜろ) にし），部分的な関係性だけを計算させる設計も可能です．

# [06: Slide 21/24] アーキテクチャと事前知識
この接続のパターン設計を「モデルのアーキテクチャ（[Network Architecture](ネットワーク・アーキテクチャ)）」と呼びます．

画像認識なら近傍のピクセルだけを繋ぐ [CNN](シーエヌエヌ)，時系列なら過去を繋ぐ [RNN](アールエヌエヌ) のように，扱うデータ構造に合わせて接続パターンを制限することで，人間側の「事前知識（インダクティブバイアス）」をモデルに組み込むことができます．
この接続の仕方の自由度こそが，ニューラルネットワークが広く使われている大きな理由です．
これらは講義の第二部で詳しくお話ししていきます．

# [06: Slide 22/24] 今回のまとめ
今回のまとめです．
ニューラルネットワークは「マクロなレイヤーの積み重ね」と「ミクロなユニットのネットワーク」という [2](ふた)つの視点があり，数式と図が一致していることを学びました．

# [06: Slide 23/24] 次回のロードマップ
次回は，このネットワークの重みパラメータを，データから自動的に調整する「最適化」について説明します．

# [06: Slide 24/24] 活性化関数の必要性（非線形性）【補足】
ここで，[1](ひと)つ発展的な補足をしておきます．「なぜ活性化関数を挟まなければならないのか？」という疑問についてです．

もし，活性化関数を挟まずに線形変換だけを重ねたら何が起きるでしょうか．
[2](に)層重ねたモデルを例にして考えてみます．入力 [x](エックス) に対し，活性化関数なしで [2](に)層を重ねると，全体の出力は [f(x) = W_2 ( W_1 x + b_1 ) + b_2](エフ・エックス・イコール・ダブル・に・かっこ・ダブル・いち・エックス・たす・ビー・いち・かっこ・たす・ビー・に) と表されます．
これを展開して整理すると，[(W_2 W_1) x + (W_2 b_1 + b_2)](ダブル・に・ダブル・いち・エックス・たす・ダブル・に・ビー・いち・たす・ビー・に) と書き換えることができます．
ここで，新しい行列 [W = W_2 W_1](ダブル・イコール・ダブル・に・ダブル・いち) と，新しいベクトル [b = W_2 b_1 + b_2](ビー・イコール・ダブル・に・ビー・いち・たす・ビー・に) と置けば，結局は単なる [1](いち)層の線形変換と同じ形になってしまいます．

つまり，活性化関数がないと，何層重ねても結局は [1](いち)層分の複雑さの関数しか表せないことになります．
表現力を高めるために非線形な活性化関数が必須なのです．
