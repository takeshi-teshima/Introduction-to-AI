
## 対象とする読者と読み方

### 学生
変化の予測が難しい現代において，本書の内容が全て無駄にならないとは言えないが，
時代が変わっても陳腐化しない基礎的な知識を多く身につけられる教科書となるよう，内容を厳選した．
教養の一つとしても，今後の専門性の基礎としても，本書で扱った情報技術に触れておいて損はないだろう．
莫大な情報量のある分野だが，コンパクトに短期間で読める一冊として，自主的な勉強会などでぜひ活用してほしい．
本書を一冊目として読む場合の読書案内も用意したので，ぜひ参考にしてほしい．

### 機械学習やAIを活用したプロダクトを自ら開発する機会のある人（ソフトウェアエンジニア，データサイエンティストなど）
一冊目の教科書として，コンパクトにまとめたつもりである．
知っている内容も多いかもしれないが，それらの技術を扱う際に自信を持ってできるようになるための，
案件の幅を広げたり，職種の転換をしたりする際の，ちょうど良い一冊目となることを願っている．

### 機械学習やAIを活用したプロダクトづくりに関わる人（プロダクトデザイナー，プロダクトマネージャーなど）
協業をはかどらせるうえで，共通の理解の枠組みと共通言語があるとよい．
本書によって，専門家と協業できるポテンシャルを伸ばせるだろう．

## 本書のねらい
本書では知識をコンパクトにまとめることを目指した．
内容の詳しさとしては，専門家が「おっ，この人は分かってるな」と安心して会話を始めるぐらいのラインを目指した．
